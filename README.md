# Online Bookstore Database System

## Description
A relational database system designed for an online bookstore platform.  
The project supports customer accounts, inventory management, shopping cart functionality, and sales reporting.

## Technologies Used
- SQL
- MySQL
- PHP
- HTML
- CSS
- JavaScript

## Features
- User authentication and account management
- Shopping cart and order processing
- Inventory and book management
- Sales reporting and analytics
- Database triggers and constraints
- Admin and customer modules

## Concepts Applied
- Relational Database Design
- SQL Queries
- Database Normalization
- Triggers and Constraints
- Data Integrity
- Backend Integration

## Project Structure
- `admin/` → Admin functionalities
- `customer/` → Customer operations
- `database/` → Database scripts and schema
- `includes/` → Shared backend components
- `css/` → Styling files
- `js/` → JavaScript functionality
